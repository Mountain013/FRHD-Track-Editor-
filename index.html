Shortcuts & Tips

Modes & Drawing

  • Manual Mode: Q Line   W Line+   R Curve   B Bridge   A Brush   E Eraser   P Polygon   O Circle   U Box
  • Hybrid Mode: T Tube   F Fill   G Gradient   X Text
  • Automation Mode: Procedural Generators (incl. Perspective Shadow), Optimizer, Masks & Image Vectorizer
  • Tab — Rotate Mode (Manual → Hybrid → Automation)   L — Toggle Layer   N — Radar View
  • \ — Toggle Zen Focus Mode   [ / ] — Eraser Radius (Shift ±10px)
  • Middle Click / Space+Drag — Pan camera   Shift — Snap to vertex (or 15° angle lock away from vertices)
  • Alt (hold while drawing) — force solid line

Perspective Grid

  • Configure in Layers → Perspective Grid: 1-Point, 2-Point, 3-Point, or Isometric
  • Snap Modes: No-Snap, Grid-Snap (rays/intersections), Angle-Snap (configurable cone + Axis Lock)
  • Presets & Follow Camera: Built-in presets, custom Bookmarks, Level horizon, and camera-relative VPs
  • Select Extrude / Array: 3D Extrude & 1/z Foreshortened Array toward VP1/VP2/VP3; perspective Fill & Gradient hatching
  • Edit VPs — drag vanishing points on canvas (Shift levels horizon · Esc exits)
  • Right-click → Perspective Snap or status bar Persp pill — cycle perspective snap modes

Line Patterns

  • Solid, Dashes, Dots, or Noisy — applies to Line, Line+, Brush, Polygon, Circle and Fill
  • Min Stroke Length — reject whole strokes shorter than N units
  • Point Spacing (Brush only) — minimum distance between recorded points
  • Pattern Scale — multiplies dash/gap/noise clump sizes
  • Noise Coverage — 0% = nothing, 50% = half on, 100% = solid
  • Patterns are baked in at draw time — no un-dashing or re-randomizing after

Select Tool

  • S or V — Select tool
  • Drag to draw box — selects clipped fragments
  • Ctrl/Cmd+drag — add another box
  • Shift+drag — subtract a box
  • Click empty canvas — clear selection
  • Delete / Backspace — delete selection
  • Ctrl+C / Ctrl+V — copy / paste selection
  • Esc — clear selection / cancel placement

Modify Tool

  • M — Modify tool
  • Click a vertex to select, drag to move
  • Delete / Backspace — remove selected vertex

Global

  • Ctrl/Cmd + Z Undo   Ctrl/Cmd + Shift + Z / Y Redo
  • Ctrl + [ Toggle Sidebar Collapse (Slim Icon Strip)
  • Right-Click Context Menu for quick actions
  • ? / F1 — This help
  • Scroll — Zoom

Objects

  • Save a selection as a reusable object via the Select tool panel
  • Open the Objects button in the header to browse / insert
  • Click Insert on an object — a ghost follows your cursor
  • Click canvas to place — Esc / right-click cancels
